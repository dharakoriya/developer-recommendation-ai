# DevAlign AI — Research & ML Lab Guide

The sidebar under **Research & ML Lab** contains **4 dedicated pages** designed specifically for research validation, model benchmarking, dataset auditing, and prediction governance.

This guide details each page, its route, purpose, data sources, target audience, and Viva demonstration strategy.

---

## The Four Research & ML Lab Pages

```
Research & ML Lab Section (Admin Only)
 ├── 1. ML Model Evaluation & SHAP           (/research/ml)
 ├── 2. Research Dataset & Label Validation  (/research/dataset)
 ├── 3. Dataset & Collection Monitoring      (/research/dataset/monitoring)
 └── 4. Recommendation Audit & Governance   (/recommendations/audit)
```

---

### Page 1: ML Model Evaluation & SHAP Feature Attributions
- **Route**: `/research/ml`
- **Purpose**: Displays offline cross-validation performance, test metrics (ROC-AUC, PR-AUC, F1 score, Optimal Threshold), and **Global SHAP Feature Importance Rankings** for experimental Random Forest and XGBoost candidate models.
- **Data Consumed**: JSON metadata from `research/ml/artifacts/evaluation_metrics.json` via backend endpoint `GET /api/recommendations/research/ml/metrics` and `GET /api/recommendations/research/ml/explainability/global`.
- **Target Audience**: AI Researchers, ML Engineers, Project Owner.
- **Modifies Database?**: No.
- **Production or Research?**: **Research Only**.
- **Viva Demo Strategy**: Show how SHAP values reveal top feature drivers (e.g. `weighted_skill_match_score`, `dev_workload_score`) used by experimental ML models. Highlight that baseline-v2 remains active in production.

---

### Page 2: Research Dataset & Label Validation
- **Route**: `/research/dataset`
- **Purpose**: Inspects observational data collection quality, class imbalance ratios, ground-truth label validation counts (human-validated vs weak labels), and multi-criteria training readiness checks.
- **Data Consumed**: Ground-truth statistics from PostgreSQL tables `research_observational_features` and `ground_truth_labels` via backend `GET /api/recommendations/research/dataset/statistics`, `/quality`, and `/readiness`.
- **Target Audience**: Data Scientists, Machine Learning Auditors.
- **Modifies Database?**: No (Read-only research view).
- **Production or Research?**: **Research Pipeline**.
- **Viva Demo Strategy**: Demonstrate how DevAlign enforces multi-criteria readiness (e.g., requiring 200+ validated labels and 0 temporal leakage flags) before allowing an ML model candidate to advance.

---

### Page 3: Real-World Data Collection & Research Monitoring
- **Route**: `/research/dataset/monitoring`
- **Purpose**: Tracks observation accumulation rates over time (weekly/monthly snapshots) and analyzes the **Outcome Conversion Funnel** (`RECOMMENDED` → `ACCEPTED` → `ASSIGNED` → `COMPLETED`).
- **Data Consumed**: Audit outcomes from `recommendation_audits` and `recommendation_feedback` via `GET /api/recommendations/research/dataset/monitoring` and `/outcomes`.
- **Target Audience**: Product Lead, Engineering Director.
- **Modifies Database?**: No.
- **Production or Research?**: **Research Monitoring**.
- **Viva Demo Strategy**: Show the 4-step outcome lifecycle conversion funnel and highlight how user acceptance feeds back into data quality.

---

### Page 4: Recommendation Audit & Model Governance Log
- **Route**: `/recommendations/audit`
- **Purpose**: Provides an **immutable, auditable log** of every recommendation generated by DevAlign, recording exact timestamps, candidate developer IDs, rank, compatibility scores, model version (`baseline-v2`), environment, and feature vector snapshots.
- **Data Consumed**: PostgreSQL `recommendation_audits` table via `GET /api/recommendations/audit`.
- **Target Audience**: Compliance Officers, Engineering Managers, System Admins.
- **Modifies Database?**: No (Records are created automatically whenever recommendations are generated).
- **Production or Research?**: **Production Model Governance & Provenance**.
- **Viva Demo Strategy**: Show that every AI decision in DevAlign has a permanent, timestamped provenance record to guarantee complete transparency and auditability.
