# DevAlign AI — Viva Feature Guide

## Top 10 Features to Demonstrate in a Viva Presentation

1. **Intelligent Developer Recommendation Engine (`baseline-v2`)**: Demonstrates transparent 7-factor developer matching with exact factor contributions and hard eligibility rules.
2. **AI Project Planning Wizard**: Demonstrates decomposing high-level project goals into structured tasks using Heuristic/Ollama/OpenAI providers with 1-click database plan approval.
3. **Task Weighting Engine**: Shows how complexity, priority, effort, and skill difficulty combine into a normalized Task Weight (0-100) and category (Light, Moderate, Heavy, Critical).
4. **Workload Capacity & Utilization Engine**: Shows real-time workload score tracking, capacity utilization charts, and anti-monopoly protection.
5. **Multi-Level Risk Assessment & Decision Support**: Demonstrates task, developer delivery, and project risk scoring with human-readable drivers and recommended manager actions.
6. **ML Model Evaluation & SHAP Feature Attributions**: Demonstrates candidate Random Forest and XGBoost model benchmarking with global SHAP feature importance charts in the Research Lab.
7. **Developer Performance Analytics & Tiering**: Shows completion rate, on-time rate, weighted productivity, and performance tiering.
8. **Gamification & Incentive Rewards**: Demonstrates streak counters, difficulty bonus points, achievement badges (`STREAK_5`, `HEAVY_LIFTER`), and incentive ledgers.
9. **Recommendation Audit & Model Governance Log**: Demonstrates immutable audit trail logging prediction timestamps, ranks, model versions, and feature vector snapshots.
10. **Developer Sorting & Skill Proficiency Matrix**: Shows multi-attribute server-side developer sorting (Name, Experience, Performance, Workload, Availability, Completion, Productivity).

## Top 5 Most Technically Impressive Features

1. **Baseline-v2 7-Factor Compatibility Engine**: Combines transparent weighted scoring with non-linear anti-monopoly penalties and hard eligibility exclusions.
2. **Global SHAP Explainability Integration**: Extracts Shapley value attributions across candidate ML models to explain feature importance rankings.
3. **Resilient Multi-Provider AI Planner**: Polymorphic design supporting cloud OpenAI, local Ollama, and offline Heuristic engines with seamless fallback.
4. **Multi-Signal Risk Decision Support System**: Integrates schedule expiration, workload pressure, skill gap ratios, and task complexity into unified risk scores.
5. **Ground-Truth Data Collection & Outcome Funnel**: Tracks recommendation outcomes (`RECOMMENDED` → `ACCEPTED` → `ASSIGNED` → `COMPLETED`) for real-world research monitoring.
